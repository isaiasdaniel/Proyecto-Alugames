# 🎮 Proyecto Alugames

## 📌 Sobre

Este proyecto fue desarrollado por **Isaias Daniel** durante el **curso de Lógica de Programación**.  
Se trata de una simulación de plataforma para **alquiler de videojuegos**, utilizando HTML, CSS y JavaScript para aplicar lógica, manipulación del DOM y estructuras básicas de programación.

## ✨ Funcionalidades básicas

- 📦 Cálculo del costo de alquiler por tiempo de uso
- 🎮 Visualización del nombre y tipo del juego
- 🕹️ Aplicación de lógica condicional (como descuentos, validaciones, etc.)
- 📱 Diseño adaptable y limpio
