# 🎮 Proyecto Alugames

## 📌 Acerca del proyecto
Este proyecto fue desarrollado por **Isaias Daniel** durante el **curso de Lógica de Programación**.  
Se trata de una simulación de plataforma para el **alquiler de videojuegos**, utilizando **HTML, CSS y JavaScript** para aplicar lógica, manipulación del DOM y estructuras básicas de programación.

## ✨ Funcionalidades básicas
- 📦 Cálculo del **costo de alquiler** en función del tiempo de uso  
- 🎮 Visualización del **nombre y tipo de juego** seleccionado  
- 🕹️ Aplicación de **lógica condicional** (validaciones y posibles descuentos)  
- 📱 Diseño adaptable y limpio  

---

## 📖 Regla de negocio
- El usuario selecciona un **videojuego** de la lista.  
- Debe indicar la **cantidad de horas o días** de alquiler.  
- El sistema calcula el **precio total** multiplicando el tiempo por la tarifa base.  
- Se aplican **validaciones**:  
  - Si el tiempo ingresado no es válido, muestra un mensaje de error.  
  - Se pueden aplicar **descuentos especiales** si el tiempo de alquiler supera un límite (ejemplo: más de 7 días).  
- El resultado se muestra dinámicamente en pantalla.
